Lil Guys GAMES.md

Formats for games

Any player's lil guy, from one address. Type a name: a claimed one shows as it's worn, any other name shows the guy it deals. Each picture plays by itself in a plain <img>.

Where it goes

The sizes the club's games use, each one line of script: LilGuys.lilGuyImg(name, 'row').

Every view

At 1× and at a size you'd show it. Every view comes as .png (animated when it moves), .gif, and a sprite sheet with its frame times.

Sizes

View1×MovesUse it for

Ask for @1 and scale it up in CSS with image-rendering: pixelated: as sharp at any whole-number size, a fraction of the bytes. @2 to @16 are for places that don't run CSS (Discord, email). Addresses under /g/latest/ always find today's art.

A whole board in one read

GET /api/club/batch?names=… (up to 100) answers every name's guy, claimed or not, with ready addresses: LilGuys.lilGuysFor(names).
